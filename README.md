**Data Analysis of Restaurant Spending Patterns Using Python**

**Project Overview**
This project explores restaurant spending patterns through exploratory data analysis using Python. Using a dataset of 244 restaurant transactions, 
the analysis examines differences in spending across days and meal periods, tipping behaviour, and the relationship between 
dining group size and total expenditure.

**Research Questions**

1.) How does average restaurant spending vary across different days of the week?

2.) Do average transaction values differ between lunch and dinner?

3.) Is there a relationship between total restaurant bills and tips?

4.) How does dining group size relate to total spending?

**Dataset**

The project uses the Tips dataset available through the Seaborn Python library.
Observations: 244
Variables: 7
Source: Seaborn Tips Dataset

**Tools And Technologies Used:**

Python
Pandas
NumPy
Matplotlib
Seaborn
Google Colab

**Methodology**

The analysis is involved with the following stages step by step:
Data exploration: Examining dataset dimensions, variable types and missing values.
Descriptive statistics: Calculating summary statistics to understand numerical variables.
Data aggregation: Grouping observations to compare average spending across days and meal periods.
Correlation analysis: Using Pearson correlation coefficients to examine relationships between numerical variables.
Data visualisation: Creating bar charts and scatter plots to communicate analytical findings.


**Key Findings**

1)Sunday recorded the highest average restaurant bill among the observed days.
2)Dinner transactions had a higher average bill than lunch transactions.
3)Total bill and tip amount showed a positive correlation of 0.676.
4)Party size and total bill showed a positive correlation of 0.598.
5)Average transaction values generally increased with dining group size.

Taking through the theoretical aspect in " The Practice of Everyday Life ( 1984 ), by Michel de Certeau, he challenges the understanding of 
consumers as merely passive participants within the systems of production. He argues that consumption is also an everyday practice through which

for examining this dimesion of consumption, although the dataset cannot establish a central desginated cultural meaning behind these interactions 
as they are entirely individualistic and psychological in nature. However, this may be subjectively concluded in the notion that these numerical patterns 
in consumer transactions can be understood as a one dimension of a wider cultural context in which consumption takes place. Although, reducing the 
lived experiences to data, cannot automatically nullify the human behaviour and cultural context attached to the spendings especially if viewed through 
the lens of comparative analysis section.


**Limitations**

The analysis uses a pre-existing dataset of 244 transactions and is not intended to represent consumer behaviour more broadly. 
The findings are descriptive and identify associations rather than causal relationships. 
The project does not include predictive modelling or inferential statistical testing.
